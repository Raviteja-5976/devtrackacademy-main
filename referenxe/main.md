# DevTrackAcademy Homepage Design Prompt

*A detailed AI prompt for building a modern Neo-Brutalist landing page in Next.js.*

---

# Project Overview

Design and develop a premium, highly interactive landing page for **DevTrackAcademy**, an online platform that teaches software development through workshops and practical project-based courses.

The design language should be **Modern Neo Brutalism**, combining bold typography, thick borders, playful layouts, vibrant colors, oversized cards, subtle imperfections, and fluid animations without sacrificing usability.

The website should feel like a mix of:

* Linear's smooth animations
* Framer's interactions
* Figma's polish
* Neo Brutalist boldness
* Apple's spacing
* Stripe's smoothness

The overall experience should feel energetic, modern, premium, and handcrafted.

## Overall Experience

The final result should feel like a **living, interactive product landing page** rather than a static website. Every scroll should reveal something delightful, with smooth GSAP-powered storytelling, Framer Motion micro-interactions, and a bold Neo-Brutalist aesthetic. The interface should balance playfulness with professionalism, using oversized typography, thick borders, layered cards, expressive illustrations, and generous whitespace. Every section should have a distinct visual identity while maintaining a cohesive design system based on the provided color palette. The homepage should be highly polished, responsive, performant, and production-ready, comparable in quality to modern startups like Linear, Framer, Raycast, and Vercel while retaining a unique DevTrackAcademy personality.
